Сапер - Игра на Python
📋 Описание проекта
Сапер - это классическая игра-головоломка, полностью переработанная с современной графикой, анимациями и звуковыми эффектами.

1)Особенности
Визуальные эффекты
Анимированный фон с градиентом и звездами
Частицы с плавным движением
Клетчатое поле на заднем плане с медленным движением
3D эффекты для клеток игрового поля
Плавные анимации появления элементов

2)Уровни сложности
Новичок: 9×9 поле, 10 мин
Любитель: 16×16 поле, 40 мин
Продвинутый: 16×30 поле, 99 мин
Эксперт: 20×30 поле, 150 мин
Мастер: 24×40 поле, 250 мин

3)Управление
ЛКМ: Открыть клетку
ПКМ: Поставить/снять флажок
СКМ: Поставить знак вопроса
ESC: В главное меню
R: Начать заново (после игры)

4)Как играть
Основные правила
Цель игры: Открыть все клетки, не содержащие мин
Числа в клетках: Показывают количество мин в соседних клетках
Флажки: Отмечают предполагаемые мины
Знаки вопроса: Отмечают клетки, в которых вы не уверены
Игровой процесс
Начните с левого клика на любой клетке
Используйте числа, чтобы определить расположение мин
Отмечайте мины флажками (правый клик)
Открывайте безопасные клетки
Избегайте мин!
